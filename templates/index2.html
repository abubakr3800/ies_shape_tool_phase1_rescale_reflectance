Step 2

Room Shape

Rotate/flip work whichever way you entered the shape — drawn on canvas or pasted as JSON below — spinning/mirroring it around its own bounding-box center. Fixtures don't move with it either way.

Click on the workspace canvas below to place points, then click the first (green) point again — or hit Close Shape — to finish the outline. Once closed: drag a white dot to move a corner, drag a grey diamond (mid-edge) to bow that side into a curve, double-click an edge to add a corner there, and double-click (or right-click) a corner to remove it. Every edge shows its length — click a length label at any time to type an exact value for that side.

Shortcuts: Ctrl+Z / Ctrl+Y undo/redo any change · select a corner then Delete removes it or the arrow keys nudge it (hold Shift for a bigger step) · Escape cancels the outline or hole you're currently drawing.

Pick a shape, then set its dimensions — a named polygon (triangle through octagon) can be sized either by the distance from center to corner or by the length of one side; pick "Custom regular polygon" for any other number of sides. Circle/oval smoothness controls how many straight edges approximate the curve (higher = rounder, but more points for the calculation grid to consider).

Step 3

Fixtures

Photometric output override

Leave blank to use the IES file's own declared output as-is. Enter a value to rescale the candela distribution — this is the same thing DIALux does when you edit a luminaire's Luminous Flux away from its photometric file's declared total (e.g. matching a real product's datasheet lumens instead of the raw file).

Fixtures are now editable on the workspace canvas above: drag one to reposition it, or switch mode below to click-add or click-remove. Add Row/Column duplicates the outermost row/column at the given spacing (skipping any point that would land outside the room shape).

Room & maintenance

Reflectances default to the typical DIALux/CIE new-project values (Ceiling 70% · Walls 50% · Floor 20%) — edit to match your actual room finishes. The indirect (interreflected) component this produces is a room-average approximation, not a per-point radiosity solve like DIALux's — see the result panel's note.

By default every calculation stretches red-to-blue across its own min/max lux — so two runs with a similar overall range can look almost identical even after a fixture moved, because the scale re-normalizes around whatever the new numbers are. Check Lock color scale to fix the min/max instead (pre-filled from your first calculation, editable any time), so the same lux value always maps to the same color and a small, local change stays visible run to run. Show lux values on grid prints the exact reading at every point directly on the heatmap; on a fine grid where the numbers would overlap, hover any point instead to read its exact value and coordinates in the tooltip.
